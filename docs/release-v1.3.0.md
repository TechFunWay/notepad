# 记事本 v1.3.0 更新日志

发布日期：2026 年 8 月 20 日

本次更新重点接入飞牛 fnOS 统一网关登录，优化宽屏写作体验，并修复飞牛网关下的笔记图片显示问题。

## 重点更新

### 飞牛 NAS 统一网关登录

- 接入飞牛 NAS 统一网关登录：在飞牛桌面的应用入口可直接使用 NAS 账号登录，无需再输入账号密码。
- 首次使用支持通过「使用飞牛 NAS 账号设置管理员」初始化管理员，输入管理员账号密码后自动与飞牛账号绑定。
- 点击飞牛登录后弹出授权确认窗口：可确认当前飞牛账号登录，也可切换到其他飞牛账号。
- 切换其他飞牛账号在弹窗登录框中完成，授权后自动返回记事本。
- 已有安装可创建应用账号，或验证并绑定已有应用账号，之后即可使用飞牛账号登录。
- 退出记事本只清除当前应用会话，不影响飞牛 NAS 系统登录状态。

### 宽屏写作体验

- 工作台充分利用宽屏空间，最近笔记根据可用宽度自适应分列展示。
- 富文本编辑器与预览正文在宽屏下内容宽度更宽，小屏幕自动收缩。
- 优化手机端个人设置页面的显示间距。

### 图片显示修复

- 修复飞牛环境点击上传图片后正文只显示破图的问题。
- 修复从剪贴板粘贴图片后无法正常显示的问题。
- 已保存的旧图片路径会自动适配飞牛应用网关前缀。
- 图片仍保存为通用路径，不影响 Docker 和直接运行方式。

## 升级说明

- 可直接从 `v1.2.x` 升级，无需手动执行数据库迁移。
- 飞牛应用中心安装新版后，已有数据与应用账号保持不变；可通过「验证并绑定」将飞牛账号与已有应用账号关联。
- Docker 和直接运行方式的账号密码登录保持不变。
