# 记事本 v1.2.0 更新日志

发布日期：2026 年 8 月 7 日

本次更新重点改善手机端使用体验和登录稳定性，同时补齐标签管理能力，并解决应用升级后偶发白屏的问题。

## 重点更新

### 手机端体验全面优化

- 重构响应式页面布局，优化手机、平板和桌面端的显示效果。
- 调整移动端导航、笔记列表、编辑器和操作区域，减少遮挡与横向溢出。
- 优化登录、注册、找回密码、个人资料及管理页面的小屏幕布局。
- 支持将记事本添加到手机主屏幕，并补充 180、192、512 像素应用图标。
- 支持独立窗口方式打开主屏幕快捷方式，使用体验更接近原生应用。

### 标签管理增强

- 新增标签管理面板，可查看标签数量及关联笔记数。
- 支持重命名标签，并自动更新所有关联笔记。
- 支持移除标签，不会删除笔记内容。
- 支持从标签管理面板直接筛选并查看关联笔记。
- 优化笔记编辑时的标签录入、建议、展示和移除操作。

### 登录状态更稳定

- 修复未配置 `JWT_SECRET` 时，应用重启会导致所有设备登录失效的问题。
- 自动生成的登录签名密钥现在会保存到数据目录，并在后续启动时继续使用。
- 登录有效期由 7 天延长至 30 天，减少手机端频繁重新登录。
- 手动配置的 `JWT_SECRET` 仍具有最高优先级。

### 升级与访问稳定性

- 首页和 SPA 路由入口改为禁止缓存，升级后可及时加载最新前端资源。
- 已失效的旧版 JS、CSS 静态资源会正确返回 404，不再错误回退到 HTML 页面。
- 修复浏览器保留旧资源引用时可能出现的升级后白屏问题。

### 发布与部署

- 版本升级至 `1.2.0`，并补充数据库版本记录。
- 修复多平台发布脚本未注入版本号、构建时间和 Git 提交信息的问题。
- 支持构建 Linux、macOS、Windows、飞牛 fnOS 及 Docker 多架构产物。
- Docker 镜像同时支持 `linux/amd64` 和 `linux/arm64`。

## 升级说明

- 可直接从 `v1.1.0` 升级，无需手动执行数据库迁移。
- 因旧版本每次启动使用随机登录签名密钥，升级到 `v1.2.0` 后现有用户可能需要重新登录一次。
- 完成这次登录后，只要数据目录没有被删除，应用或设备重启都不会再导致登录状态丢失。
- Docker 和飞牛用户应确保应用数据目录持久化且可写。

## 本次发布产物

- Linux amd64 / arm64
- macOS amd64 / arm64
- Windows amd64
- 飞牛 fnOS amd64 / arm64
- Docker linux/amd64 / linux/arm64
