# 记事本 v1.2.5 测试版更新记录

发布日期：待测试通过后确定

当前版本用于验证飞牛 fnOS 登录、首次初始化、宽屏布局及安装包构建流程，尚未作为 `v1.3.0` 正式发布。

## 本轮更新

- 首次设置管理员页：飞牛登录入口移至底部，与「设置管理员」按钮并列。
- 点击飞牛登录后，先弹出「确认使用飞牛 NAS 登录」授权窗口：可确认当前飞牛账号登录，也可切换到其他飞牛账号后再授权，取消则返回。
- 切换其他飞牛账号改为弹窗登录框完成，不再整页跳转。
- 修复：飞牛登录弹窗授权后，回调地址缺少应用前缀（`/app/techfunway-notepad/`），导致回调页无法加载、切换账号登录后显示空白页。
- 首次初始化：飞牛授权后仍需输入应用管理员账号密码创建并绑定，不再静默创建管理员。

## 待验证内容

- 飞牛桌面入口以新窗口打开。
- 点击飞牛登录先弹出授权确认窗口，可确认当前飞牛账号登录或切换到其他飞牛账号。
- 切换其他飞牛账号在弹窗登录框中完成，授权后能正确回跳并弹出确认窗口。
- 首次初始化：飞牛授权后进入设置管理员表单，输入账号密码创建管理员并绑定飞牛登录。
- 已有安装可创建或绑定应用账号，并继续使用飞牛账号登录。
- 退出记事本只清除当前应用会话，不退出飞牛 NAS 系统账号。
- 工作台充分利用宽屏空间，最近笔记根据可用宽度自适应分列。
- 富文本编辑器与预览正文靠左排列，小屏幕自动收缩。
- 飞牛 amd64、arm64 安装包可独立构建并写入正确架构信息。
- Docker 和直接运行方式保持原有账号密码登录及访问方式。

## 发布约定

- 每轮打包均迭代下一个小版本，便于直接在飞牛应用中心更新，无需卸载重装。
- 本轮保持版本号 `v1.2.5`，不创建 `v1.3.0` 正式发布。
- 全部功能在飞牛环境测试通过后，再升级为 `v1.3.0` 并重新打包发布。
